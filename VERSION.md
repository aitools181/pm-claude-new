# Version history

Convention: **MAJOR.MINOR** — bump MAJOR for a big update (new capability area,
breaking change, major release), MINOR for a small change (fix, tweak, small addition).
The running version is shown only in the platform console (`/superadmin`), next to the title.

To change it, edit `packages/shared/src/version.ts` (`APP_VERSION`) and the root `package.json`.

| 9.6 | 2026-08-16 | UI-standards gate now passes for the first time - the four long-standing 'permanent cosmetic failures' were investigated individually rather than accepted, and each turned out to need a different resolution. (1) globals.css literal colours: three instances, all the same redundant fallback var(--red,#d1453b) - since --red is itself defined at :root in that same file, the fallback could never fire, so it was dead weight; removed. (2) Dynamic JSX styles (2): the adoption funnel bar and onboarding checklist bar both set a runtime width inline. These are exactly what the existing RuntimeStyle CSS-variable bridge was built for, so both now pass --funnel-pct/--checklist-pct through it and the width moved into the CSS rule. (3) Static JSX styles (4) and (4) hard-coded hex (1 of 2): all in app/global-error.tsx, which Next.js renders with its OWN html/body element, replacing the root layout - globals.css is therefore never loaded when it displays, so class names would be inert and inline styles are the only styling that can work. Caught one bug while writing it - the allow-list path was written app/global-error.tsx but rel() returns repo-root-relative paths, so it silently would not have matched; corrected to apps/web/app/global-error.tsx. (5) The last hex was a false positive all along: the regex /#[0-9A-Fa-f]{3,8}/ matched the copy 'case #1234' in a legal-hold placeholder, since 1-4 are valid hex digits. Refined it to require a colour context (a colour/background/border/fill/stroke/shadow property nearby) or a 6-or-8-digit hex that no reference number realistically resembles, then verified against six cases that it still catches every real violation (inline colour, 6-digit, 8-digit, shorthand background) while ignoring plain reference numbers.
